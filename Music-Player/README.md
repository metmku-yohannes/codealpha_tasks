# Music Player

A responsive music player built with HTML, CSS, and JavaScript.

## Features

- Play and pause music
- Skip to the next or previous song
- Select songs from the playlist
- Display song titles, artists, and album covers
- Search songs by title or artist
- View playback progress and seek to a specific position
- Adjust the volume
- Automatically play the next song
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Website structure
- `style.css` — Styling and responsive layout
- `script.js` — Music player functionality
- `music/` — Audio files
- `fiyorina-cover.png` — Album cover
- `yane-leje-eyalen-cover.png` — Album cover
- `kefitret-yegilish-cover.png` — Album cover

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Purpose

This project was created to practice frontend development using HTML, CSS, and JavaScript as part of a CodeAlpha internship project.
